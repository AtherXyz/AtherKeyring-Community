# Contributing

During the public Alpha phase, AtherKeyring accepts:

- bug reports;
- game/app compatibility reports;
- ideas;
- questions;
- screenshots/videos from testers;
- usability feedback.

## No code contributions during Alpha

The product source code is private during Alpha. Pull requests with source code are not accepted at this stage.

Do not submit:

- source patches;
- scripts;
- executable plugins;
- APK modifications;
- automation intended to run inside AtherKeyring;
- signing files;
- credentials.

## Feedback flow

Discussion → evaluation → Issue if accepted and delimited → internal roadmap only after owner approval.

Not every idea becomes a planned feature, and not every compatibility report becomes an official support promise.
