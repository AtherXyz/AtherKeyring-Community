# Compatibility

AtherKeyring is an Android overlay. Compatibility depends on the device, Android version, game/app, orientation, haptics, and how the game handles touch input.

Waydroid and emulators are useful for inspection, but real compatibility must be confirmed on physical phones.

## Haptics guidance

AtherKeyring has its own haptics.

If a game or app already uses intense vibration/haptics, testers are encouraged to try disabling AtherKeyring haptics.

The keyboard may suspend AtherKeyring haptics depending on the current behavior, but AtherKeyring does not claim to automatically detect haptics from external games/apps.

## Public compatibility classification

| Status | Meaning |
|---|---|
| GREEN | Overlay and haptics work well. |
| YELLOW | Overlay works; recommended to disable AtherKeyring haptics. |
| ORANGE | Partial compatibility or needs more testing. |
| RED | Important interference or breakage. |

These statuses are based on tester reports. They are not promises of official support.
