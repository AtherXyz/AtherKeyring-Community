# Security Policy

Security vulnerabilities must not be reported in public Issues or Discussions.

## Reporting security issues

Use a private channel configured by the repository owner, or GitHub Private Vulnerability Reporting if it is enabled for this repository.

Do not publicly disclose exploitable details before a fix or mitigation is available.

## Public Alpha security model

During Alpha, users may:

- download approved APKs;
- report bugs;
- report compatibility;
- suggest features;
- share screenshots/videos that do not contain sensitive data.

Users must not:

- upload or execute code inside AtherKeyring;
- load executable plugins;
- modify behavior through scripts;
- access signing keys;
- write directly to product branches;
- inject content into privileged pipelines.

Code contributions are not accepted during this Alpha phase. Feedback, bug reports, compatibility reports, and ideas are welcome.

## Sensitive information

Never upload:

- passwords;
- tokens;
- private documents;
- signing keys;
- keystores;
- `.env` files;
- logs containing personal information.
