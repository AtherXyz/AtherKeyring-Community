# Problemas conocidos y límites

Referencia: **0.5.0-alpha1 /110**. Ather ha aceptado esta integración como checkpoint;
la corrección de errores y las pruebas en otros dispositivos continúan.

| Área | Estado / qué tener en cuenta |
| --- | --- |
| Caducidad | 7 días desde el primer inicio; actualizar109→110 no reinicia el plazo |
| Datos de Alpha 13 | No se importan automáticamente a la instalación de integración |
| Exportación | La carpeta AtherKeyring debe crearse y seleccionarse manualmente |
| Guardado interrumpido | Sigue abierta una comprobación de posible duplicado si se interrumpe el guardado y se reintenta; reporta el caso antes de borrar notas |
| Gestos de Mini Office | La matriz completa con nota vacía, texto/foto, teclado y cancelaciones continúa en prueba |
| Permisos y compatibilidad | Cámara, captura, overlay, orientación y juegos requieren pruebas por dispositivo |
| Accesibilidad | TalkBack, fuentes grandes e insets no tienen validación completa |
| Hápticos | Experimentales; se pueden desactivar si interfieren con un juego |
| Complementos futuros | «Próximamente» no permite comprar ni equipar |
| Privacidad | Almacenamiento local sin bóveda/cifrado propio; evita contenido sensible |

El editor de hitboxes es una herramienta tester: cuando está activo bloquea acciones de
Guardar/Papelera/Descartar. Desactívalo para probar los gestos normales.

No se promete compatibilidad con todos los juegos ni multitouch independiente sobre cualquier app.
Los informes históricos no se presentan como fallos reproducidos de110 sin comprobarlos.
